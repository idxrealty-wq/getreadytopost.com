# GetReadyToPost - Rate My Listing

Real estate listing analyzer that grades listings and provides actionable feedback.

## Getting Started

1. Install dependencies: `npm install`
2. Add Firebase credentials to `.env.local`
3. Run dev server: `npm run dev`
4. Open http://localhost:3000

## Features

- Instant listing analysis
- 6-category grading system
- Rewritten descriptions
- Actionable recommendations
- Visual scoring

## Deployment

Deploys automatically to Netlify on push to main.
